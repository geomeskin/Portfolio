NCDOT AGOL Accessibility Compliance Program

A comprehensive ADA / WCAG 2.1 Level AA accessibility compliance program for all public-facing ArcGIS Online content published by a state Department of Transportation. Audited 16 live Experience Builder applications using a combination of automated scanning, manual keyboard testing, and a custom-built JavaScript audit tool that checks 13 accessibility criteria in a single browser console pass.

Produced 8 formal deliverables including an 83-item master checklist, a full Phase 1 findings report, an executive briefing for leadership, per-app remediation task lists, and a multi-app Excel audit tracker with auto-calculated compliance scores. Identified critical failures requiring immediate remediation and documented platform-level limitations for escalation to Esri. Program is ongoing across 5 planned phases through Q4 2026.
